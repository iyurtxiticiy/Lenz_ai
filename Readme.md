

# LegalLens AI – Smart Contract & Document Reader

LegalLens AI is a browser app prototype for uploading legal PDFs, reviewing plain-English summaries, checking risk areas, asking document questions, and translating difficult legal terms into Hindi.

## Run the app locally

```bash
npm run dev
```

Then open <http://localhost:5173>.

## Install it like an app

The project is configured as a Progressive Web App (PWA):

1. Run `npm run dev` or deploy the static files to any HTTPS host.
2. Open the site in Chrome, Edge, or another PWA-capable browser.
3. Use the browser install icon, or the in-app **Install app** button when the browser exposes the install prompt.
4. The app will launch in a standalone window and cache the app shell for offline loading.

## Available scripts

- `npm run dev` — serve the static app on port 5173.
- `npm run preview` — serve the static app on port 4173.
- `npm run build` — run a JavaScript syntax check for the dependency-free app.
